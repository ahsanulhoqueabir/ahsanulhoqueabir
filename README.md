### About

I build production web applications end to end, from the database schema and API to the interface people actually use. Over the past three years I have shipped point-of-sale systems, e-commerce storefronts, inventory and accounting modules, and campus platforms used by real students and universities.

My day-to-day stack is **Next.js, React, TypeScript and Node.js**. I care about clean, maintainable code and user-centric design, and my background in competitive programming shapes how I approach problems: understand the constraints first, then build the simplest thing that holds up.

- **Now:** Full Stack Developer at [abgen.it](https://abgen.it) (2023 – present), building POS, e-commerce, inventory and financial modules with role-based access control.
- **Also:** Webmaster of IEEE Jagannath University, where I redesigned the official website and lead the student development team.
- **Interests:** full-stack architecture, developer tooling, automation, and new technologies that solve problems more efficiently.

#### [GigHub](https://github.com/ahsanulhoqueabir/GigHub) &nbsp;·&nbsp; [Live](https://gighub.ahsanull.com)

`Next.js 16` `TypeScript` `MongoDB` `Python` `GitHub Actions`
